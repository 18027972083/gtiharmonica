================================================================
  大肥鲸洲琴工具包 —— 三角洲行动口琴自动演奏
  使用说明
================================================================

【这是什么】

一个小工具：导入 MIDI 或曲谱文件，它会自动帮你把曲子"吹"出来——
程序按节拍向游戏发送按键，游戏里的口琴就会响。

不需要安装 Python，不需要联网，不写入系统目录。
双击 大肥鲸洲琴工具包.exe 就能用。


【第一次使用：五步走】

1. 打开游戏，取出口琴，进入可以演奏的界面。
   建议把游戏画面设为"无边框窗口"模式，方便切换。

2. 确认游戏里的口琴按键和本程序一致（默认就是游戏的默认设置）：
      音阶键：  Z  X  C  V  B  N  M  ,
      鼠标左键按住 = 降低一个八度
      鼠标中键按住 = 升高半音
      鼠标右键按住 = 提高一个八度
   如果你改过游戏键位，请先改回来，或在本程序的配置文件里同步修改。

3. 打开本程序，点工具栏的「校准」。
   - 先点「开始基准测试」，看注入延迟是否正常。
   - 再点「开始测量」，测出你的游戏能识别多短的按键。
   这一步能让后面的演奏准确很多，建议不要跳过。

4. 在左边曲库里选一首曲子，点「试听」，确认旋律对不对。
   内置了 6 首示例曲，也可以点右上角的「导入 MIDI / 曲谱」添加自己的文件。

5. 点「演奏」，然后在这 3 秒倒计时内切回游戏的口琴界面。
   倒计时结束就开始自动演奏了。


【演奏中的快捷键】

    F8          暂停 / 继续
    F9 或 Esc   停止（会自动松开所有按键）

在游戏里按就行：这两个键是全局热键，程序在后台也收得到，而且不占用
按键、不影响游戏自己用 F8/F9。

倒计时那 3 秒里按 F9 / Esc 可以取消这次演奏。

切回本程序看进度会自动暂停，回到游戏按 F8 接着弹；切到别的程序会
直接停止并松开所有键，防止把按键误发到别的窗口。


【四个按钮的区别】

    演奏    真正把按键发送到游戏
    演练    不发送按键，只在界面里走一遍，用来看节奏和按键序列
    试听    用电脑自己的合成器播放，不用开游戏，适合选曲和调参
    停止    立刻中断，并松开所有按过的键


【曲谱从哪来】

方式一：导入 MIDI / 曲谱文件
* 支持 .mid / .midi 标准 MIDI 文件，以及本程序自己的 .json 格式。
* MIDI 可以在 midishow 等网站下载。
* 点右上角的「导入 MIDI / 曲谱」选文件，或直接把文件拖进窗口。

方式二：导入键位简谱
* 点右上角的「导入简谱」，把简谱文本粘进去。
* 可以解析预览、试听，满意再点「加入曲库」。

方式三：自己改
* 选中一首曲子点「编辑乐谱」，删改音符、插入空白或音阶，
  改完点「保存曲谱」写回曲库（详见程序里的「使用说明」）。


【MIDI 的两种转法：直转 与 旋律化】

MIDI 文件拖进窗口（或从「导入 MIDI / 曲谱」选中）后会让你二选一：

    直转 · 保留声部
        整份 MIDI 原样进入编排：全部音高按八度折叠收进口琴音域，
        节奏保持文件里的原始精度。旋律清晰、编曲不复杂的曲子用这种，
        结果最接近原曲。

    旋律化 · 先简化再入库
        先按十六分音符网格量化，每个时刻只留最高的那个音，拼成一条
        干净的单旋律线（低音与内声部舍弃），再进编排。编曲密集、
        声部多、直接转容易糊成一团的曲子用这种。

两种都可以各来一份，存在曲库里对比着听，挑顺耳的用。


【音频转曲谱（内置，不用装任何外部工具）】

从 v1.10 起，程序里直接内置了 GAME（OpenVPI 的歌声转 MIDI 模型）：
    点顶栏「音频转曲谱」选一个音频文件，或者直接把音频文件拖进窗口，
    本机 CPU 推理（一首 4 分钟的歌约 30 秒），转完自动加进曲库。
    支持 mp3 / wav / flac / ogg / m4a 等格式。

效果与建议
* 跟着人声 / 主旋律唱的歌效果最好。它输出的是**单条旋律线** —— 多声部的
  曲子会被自动压成主旋律（口琴本来也只能弹一个音）。
* 伴奏很满的歌会混进一些杂音：先用【分离人声】那套处理一遍再转，会干净
  很多（本机已经有拖拽式的一键分离脚本）。
* 转出来的音常见 ±1 半音漂移：在编辑器里点「调内吸附」就能修。
* 生成式模型每次结果会有极小差异（音符数 ±3%），属正常现象。

命令行（适合批量转整个目录）
    python -m gtiharmonica transcribe 目录 -o 输出目录
    打包版同样支持：
    大肥鲸洲琴工具包.exe transcribe "D:/Music/某首歌.mp3"

下面这一节是「用外部工具」的老办法（想要更精细控制、或想自己跑分离时
用得上）；日常转谱用上面内置的就行，不必再装外部工具。


【用外部工具：GAME 一键包 + 人声分离（进阶）】

内置转谱已经覆盖绝大多数情况；这一节留给想自己控制细节的人 ——
比如先做高质量人声分离、或者一次处理一整批素材。

GAME 是 OpenVPI 做的歌声转 MIDI 模型（免费开源），官网一键包和本程序
内置的是同一个模型。

1. 下载解压（Windows，免安装，不需要 Python）
   * GitHub 仓库 openvpi/dataset-tools 的 Releases 里下载
     GAME_Inference_Demo_Program_0605.zip（约 73 MB），解压到任意目录。
   * 包里自带 small 规格模型（model/GAME-1.0.3-small-onnx）。
   * 想要更好的效果：到 openvpi/GAME 的 Releases 下载 v1.0.3 的 medium
     模型，解压到同一目录，再用「Browse...」把 Model Path 指过去。

2. 转谱
   双击 GameInfer.exe：
   * Model Path     一般已自动填好（没填就 Browse 到包里的
                    model\GAME-1.0.3-small-onnx）
   * Input Audio    选音频，官方建议用单声道 WAV
   * Output MIDI    选输出位置
   * 点 Convert，等进度条走完

   【重要】别直接把整首歌喂进去：GAME 靠人声边界把音频切成不超过 60 秒
   的片段，混着伴奏时它切不出来，会直接报错
       "Slice duration exceeds 60 seconds"
   （进度卡在 10% 左右然后弹错误框）。两个办法：
     * 先把人声分离出来再整首转 —— 效果最好。分离工具都是开源的：
         - UVR5（图形界面）：GitHub 的 Anjok07/ultimatevocalremovergui，
           选 MDX-NET 里的 UVR-MDX-NET-Inst_HQ_3，只输出 vocals；
         - demucs（命令行）：pip install demucs 之后
           demucs --two-stems=vocals 歌曲.mp3
           人声在 separated/htdemucs/歌曲/vocals.wav。
     * 或者把音频手动切成 ≤55 秒的小段，逐段转换，最后按顺序把 MIDI
       拼起来（实测可行，代价是切点处可能有个别音被截断）。
   切段命令（有 ffmpeg 的话）：
       ffmpeg -i 歌曲.wav -ac 1 -ar 44100 -f segment -segment_time 55 clip_%02d.wav

   实测速度（CPU）：55 秒的一段约 10 秒转完；纯人声短片段几秒就好。

3. 导进本程序
   把生成的 .mid 拖进窗口，选「旋律化」或「直转」即可。
   扒出来的音常见 ±1 半音漂移，在编辑器里点「调内吸附」就能修；
   没做人声分离时，常会混进几段偏低的伴奏音（比如 E2 一带），
   在编辑器里框选删掉即可。

补充：GAME 只输出音高与时值，不含音高曲线；想看转出来的 MIDI 长什么样，
可以拖到 signalmidi.app 上预览。


【曲库：收藏 与 删除】

* 每首曲目右边有个星标，点一下就是收藏（点亮变实心）；右键菜单里
  也有「收藏 / 取消收藏」。
* 曲库标题右边的「全部 / 收藏」用来只看收藏的那几首，搜索照常可用。
* 收藏名单存在曲库目录里（.favorites.txt，一行一个文件名），
  想备份或换机器时跟着曲库目录一起拷走即可。

* 删除：右键曲目 → 「从曲库删除」。
  删除会被记一笔（曲库目录里的 .deleted.txt）：exe 旁边那份曲库在启动
  时的自动补齐、内置示例曲目的安装都会跳过它 —— 所以删掉的曲子不会
  下次启动又冒出来。
  想找回来：把同名文件重新导入 / 拖回曲库，删除记录会自动撤销。


【听不到声音？按顺序检查】

1. 倒计时结束的那一刻，游戏是不是在前台？
   程序把"那一刻的前台窗口"当作演奏目标，切晚了就会弹提示。

2. 游戏是不是以管理员身份运行的？
   如果是，本程序也必须右键"以管理员身份运行"，否则 Windows 会
   拦下模拟按键。这是最常见的原因。

3. 用「校准」里的「按键通过率」逐个测一下，看哪些键没反应。
   如果整组都没反应，基本就是上面第 2 条。

4. 确认游戏里已经取出口琴，并且处在可以发声的界面。


【偶尔漏音 / 节奏不稳？】

* 打开「设置」，把「自旋窗口」调小到 0.001 秒试试。
* 暂时关闭杀毒软件的实时扫描（有些杀软会拦截模拟按键）。
* 演奏时尽量不要移动角色或视角，也不要同时手动按键。


【听起来不好听？】

* 先检查「音轨」选得对不对。多音轨的曲子里，选中伴奏轨会很难听。
  点「策略分析」或看曲库信息里的覆盖率，选覆盖率最高的那一轨。
* 用「移调」把整曲挪进乐器音域。
* 降低「音符连贯度」可以让音符之间分得更清楚。
* 加大「句尾换气」能让长乐句喘得过气。


【想要更省力？】

点工具栏的「策略分析」，它会对比 4 种指法方案的：
    按键次数、修饰键切换次数、换键次数、手部移动量
选一行点「应用选中的策略」即可。

一般来说：
* 容易按错修饰键 → 选「切换最少」那一行
* 手速跟不上     → 选「按键最少」那一行
* 拿不准         → 用 optimal（默认，它按成本模型算全局最优）


【关于安全 / 合规】

* 本程序只使用 Windows 标准的模拟输入（SendInput），
  不读内存、不改游戏文件、不注入 DLL、不联网。
* 模拟键鼠属于游戏自动化的灰色地带。口琴演奏不影响竞技公平性，
  但请自行确认是否符合游戏用户协议，建议不要在排位等场景使用。
* 分享给朋友时请一并转达以上两点。因使用本工具产生的任何后果，
  由使用者自行承担。


【卸载】

直接删掉整个文件夹即可。程序不在系统里留下任何东西
（配置和日志在 %APPDATA%\GTIHarmonica，可一并删除）。


【反馈问题】

如果遇到问题，把 %APPDATA%\GTIHarmonica\gtiharmonica.log 里的内容
发给作者，能帮助快速定位。
